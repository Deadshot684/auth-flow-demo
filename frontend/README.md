# Auth Flow Implementation

## Setup Instructions
1. Open terminal and navigate to `/backend`
2. Run `npm install` then `npm start`
3. Open a second terminal and navigate to `/frontend`
4. Run `npm install` then `npm run dev`

## Notes for Review
* Frontend routes (`/login`, `/signup`) are handled via React Router.
* Forms are styled with Tailwind CSS v4.
* Axios interceptors are configured to log all outgoing payloads and incoming responses directly to the browser's inspection console for easy debugging.
